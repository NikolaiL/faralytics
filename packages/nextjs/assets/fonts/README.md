FaralyticsSans Regular/Bold are derived from Lato; its Black numeric face is derived from Archivo Black.
Sources:
- https://github.com/google/fonts/tree/main/ofl/lato (OFL.txt)
- https://github.com/google/fonts/tree/main/ofl/archivoblack (ARCHIVO-OFL.txt)
The GSUB tables were removed for Satori compatibility, and font names changed to honor reserved names. The intrinsically heavy Archivo Black is registered at weight 900, and is served as FaralyticsNumbers-Black.woff on the web. OG_FONTS uses it as the 900 weight of the existing font family; axes and regular text retain Lato Regular. The older Lato-based WOFF remains for existing cached CSS references.
