FaralyticsSans is derived from Lato Regular, Bold and Black, under the included SIL OFL license.
Source: https://github.com/google/fonts/tree/main/ofl/lato
The GSUB table was removed for Satori compatibility (unsupported extended contextual substitutions), and font names were changed to respect Lato's reserved font name. Other font data is unchanged.
The Black weight is also served as WOFF for numeric UI values.
